# 12. 빠른견적 즉시 가격 표시 기능 기획서

> **상태**: 기획 중 (미착수)  
> **연관 페이지**: `/ko/quote`, `/en/quote`  
> **연관 Phase**: Phase 6 (미정)

---

## 1. 배경 및 목적

현재 `/quote` 페이지("빠른 견적요청")는 고객이 IC 규격과 연락처를 입력하면 영업팀이 1~2 영업일 내 회신하는 구조다.  
향후에는 **고객이 폼을 제출하면 즉시 예상 가격(또는 가격 범위)을 화면에 표시**하는 기능을 추가한다.  
이를 통해 영업 응대 시간을 단축하고, 고객 전환율을 높인다.

---

## 2. 목표 사용자 플로우

```
고객 접속 → 문의유형 선택 → IC 규격 입력
  → [즉시 견적 조회] 버튼 클릭
  → 화면에 예상 단가 / 납기 / 최소 발주량 표시
  → 견적 확정 요청 또는 추가 문의로 이동
```

- 즉시 표시 가능 여부는 ERP 또는 내부 가격 DB 데이터 유무에 따라 결정
- 데이터 없을 경우: "영업팀 확인 후 연락드립니다" 메시지 표시 (현재 플로우와 동일)

---

## 3. 필요 기능 요소

### 3-1. 프론트엔드
| 항목 | 설명 |
|------|------|
| 즉시 견적 조회 API 호출 | 폼 입력 완료 시 `/api/quick-quote/estimate` 호출 |
| 결과 표시 영역 | 단가, 납기, MOQ 카드 형태로 표시 |
| 조건부 UI | 매칭 결과 있음/없음에 따라 분기 표시 |
| 견적 확정 CTA | "이 견적으로 발주 문의" 버튼 → 연락처 입력 후 접수 |

### 3-2. 백엔드
| 항목 | 설명 |
|------|------|
| `GET /api/quick-quote/estimate` | IC 규격 파라미터로 가격 DB 조회 후 예상 가격 반환 |
| 가격 DB 또는 ERP 조회 | ERP `GET /api/external/price-estimate` 또는 내부 가격 테이블 |
| 캐싱 | 동일 규격 반복 조회 방지 (Redis 또는 메모리 캐시) |
| 인증 없이 호출 가능 | 비회원 접근 허용 (rate limit 적용) |

### 3-3. 가격 DB 설계 (신규)
- 제품 카테고리 × IC 패키지 타입 × 핀수 범위 × 피치 → 단가 범위
- 관리자 페이지에서 가격 테이블 직접 편집 가능하도록 Admin UI 필요

## 4. 선행 조건

- [ ] ERP에 가격 견적 API 존재 여부 확인 (`GET /api/external/price-estimate` 또는 유사)
- [ ] ERP 미지원 시: 내부 가격 테이블 DB 설계 및 Admin 편집 UI 구현
- [ ] 표시할 가격 단위/화폐(KRW/USD) 및 표현 방식(단가, 범위, "문의 필요") 정책 결정
- [ ] 비회원 vs 회원 가격 차등 여부 결정 (membership_tier 활용 가능)
