## 2. 잘 된 점 (유지)

1. **B2B 견적 비구속** — “가견적·온라인 견적은 참고용, 공식 견적서 없이 구속력 없음” (약관 §4) → 분쟁 예방에 유리.
2. **기밀·NDA 문서 웹 업로드 금지** — Privacy §9, 약관 §5, Quick Quote 안내와 **일관**.
3. **보관 기간** — 마스터 플랜(회원 즉시 파기 / 견적 5년 / 문의 3년)과 **정합**.
4. **GDPR 쿠키 opt-in** — GA4는 동의 후만, 배너·푸터 “쿠키 설정” → **실装 방향 적절**.
5. **reCAPTCHA·Mailnara·Google** — 제3자 처리 **언급** (세부는 보완 필요).
6. **EN/KO 쌍** — 구조·조항 대칭, 글로벌 B2B에 필요.

### 3-3. 운영·브랜드

- **연락 이메일** `sbchung@innovotech.co.kr` vs 도메인 `innovosolution.co.kr` → 고객 혼란 가능. **Privacy/Terms에 “공식 문의: sbchung@…” + 향후 noreply@innovosolution.co.kr** 병기 검토.
- **Quick Quote 비회원** — 수집·이용 **동의(checkbox)** 는 구현됨 ✅; 방침에 “비회원 견적 시에도 동일 항목 수집·동의 시각 기록” 1문장 추가 권장.

## 4. 이용약관 — 🔴 필수 보완

| # | 이슈 | 위험 | 권장 조항 |
|---|------|------|----------|
| 1 | **약관 변경 = 계속 이용 시 동의** (§11) | 한국 **약관규제법** — 중요 변경 시 **개별 고지·재동의** 필요할 수 있음 | “중요 변경은 시행 7일 전 공지, 회원은 이메일·재동의” |
| 2 | **회원 탈퇴·자격 정지** 없음 | 운영 공백 | “허위 정보·약관 위반 시 이용 제한·계정 삭제” |
| 3 | **업로드 파일 IP** | 분쟁 | “평가 목적 **비독점적 사용·보관** 허용, 제3자 제공 없음(법령 제외)” |
| 4 | **회사 면책 한도** | B2B에서도 **고의·중과실·인격권** 등 강행 | 현 §8 유지 + “**제조물·설계 하자**는 별도 계약·견적서 조건 우선” 1문장 |
| 5 | **준거법·관할** | EU B2B buyer | “**ICC Incoterms·별도 구매계약**이 있으면 해당 계약 우선” (선택) |
| 6 | **서비스 중단** | — | “점검·Force majeure 시 일시 중단” |
| 7 | **가입 = 약관+Privacy 동의** | Terms intro만으로는 **가입 시 Terms checkbox**와 중복 — **역할 분리** 명확히 (Terms=이용조건, Privacy=개인정보) |

## 5. 구현 vs 방침 정합성

| 항목 | 방침 | 구현 | 판정 |
|------|------|------|------|
| Privacy 동의 시각 저장 | privacy_agreed_at | Quick Quote ✅ | OK |
| Terms 가입 동의 | 필수 | register placeholder ✅ / API 미구현 | ⚠️ API 연동 시 `terms_agreed_at` 필수 |
| GA4 opt-in | 동의 후만 | cookie-consent.js ✅ / GA ID 미연결 | OK (Phase 6) |
| reCAPTCHA | 제3자 처리 | Quick Quote 제출 시 실행 | ⚠️ 방침에 **보안 목적 처리** 명시 필요 |
| Contact 3년 보관 | 방침 | DB 미구현 | ⚠️ 구현 시 TTL·파기 배치 |
| 이메일 푸터 Privacy 링크 | 권장 | 미구현 | 🟡 Phase 3 메일 템플릿에 추가 |
| Mailnara 위탁계약 | 방침 기재 | 실제 **위탁계약서** 보관 | 🟡 내부 행정 |
